# 🕷️ Web Scraper App (React + Node.js)

This is a full-stack web scraping tool built with **React (frontend)** and **Node.js + Express (backend)**.  
It allows users to input a URL, scrape data (e.g., product titles and prices), and download the results as **CSV** or **JSON**.

---

## ✨ Features

- 🔗 Input any URL to scrape (e.g., `https://books.toscrape.com/`)
- ⚙️ Real-time scraping using Axios and Cheerio
- 📄 Export results as **CSV** or **JSON**
- 📥 Download button to retrieve scraped files
- 🌗 Light/Dark mode-ready styling with TailwindCSS
- 🛡️ CORS-enabled API

---


---

## 📦 Tech Stack

### Frontend
- React
- TailwindCSS

### Backend
- Node.js
- Express.js
- Axios (HTTP fetching)
- Cheerio (HTML parsing)
- json2csv (for CSV conversion)
